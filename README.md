# pesebre
Proyecto automatizado con Arduino y encendido y apagado con bluetooth, consiste en el movimiento de motor-reductores, transición de luces(dia y noche; amanecer ,atardecer) con centelleos o relámpagos y un rayo, movimiento de lluvia y generador de olas, usando un cilindro neumatico, usando codigo c plus plus, y diagrama de conexiones.
